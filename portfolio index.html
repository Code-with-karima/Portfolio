ERP Teaching Plan Module

I developed the Teaching Plan Module as part of the ERP system for Navrachana University. This module allows faculty members to create, manage, and update their semester-wise teaching plans efficiently. It includes features such as subject allocation, weekly topic planning, and progress tracking. The module was designed with a user-centric interface using Visual Studio Code and integrates smoothly with the university’s overall ERP system. This project highlights my ability to work on real-world software solutions in an academic environment..
